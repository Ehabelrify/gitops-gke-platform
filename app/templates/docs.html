API Docs

gitops-gke-platform — available endpoints

GET/health

Liveness/readiness check. Returns healthy status — this is the endpoint GKE will later probe to decide if this pod is alive and ready for traffic.

{"status": "healthy"}
GET/api/info

Reports which environment and which pod this specific running instance is — the field that makes a GitOps promotion across dev/staging/prod visibly provable.

{"environment": "local", "pod_name": "local-dev-machine"}
